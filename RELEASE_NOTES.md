## ADR PRO v1.0.1

ELE ADR Touch PRO log merger for Android. Reads one cell from every CSV test log and merges the values into a single file.

### What changed
- Closer visual match to the original app in the cell inspector, merge history and TEST folder sync screens.
- Behavior verified side by side against the original app on an emulator: folder and file picking, TEST folder scan and merge, aggregation, auto-save, share and history.

### Features
- Pick a folder, several CSV files, or the machine TEST root (USB or storage) and merge a date folder in one tap.
- Reads one cell per file (default `B9`, changeable in the cell settings).
- Table of extracted values, with a cell inspector that highlights the target cell in the source file.
- Merge history saved on the device.
- Save the merged CSV (also auto-saved to `Documents/ADR LOG`) or share it to other apps.
- English and Arabic interface.
